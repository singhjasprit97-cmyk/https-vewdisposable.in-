# VEW Disposable Website

This folder contains the ready-to-upload website for VEW Disposable.

## How to publish on GitHub Pages

1. Create a public GitHub repository.
2. Upload these files directly:
   - index.html
   - images folder
   - README.md
3. Go to Settings > Pages.
4. Source: Deploy from branch.
5. Branch: main.
6. Folder: /root.
7. Save.
